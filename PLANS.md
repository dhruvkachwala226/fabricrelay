# FabricRelay milestone plan

M00 and M01 are documented below. Future milestone objectives and acceptance criteria will be set when the owner approves the work.

## M00 — Project initialization

Establish repository documentation, permanent agent rules, and the challenge evidence pack. Preserve the original prompt and actual setup evidence. Verify the repository and evidence structure, internal Markdown links, ignore behavior, and credential hygiene.

## M01 — Understand and problem validation

Document the problem, personas, workflows, requirements, alternatives, proposed MVP, success targets and risks. Prepare a Surat interview and task-observation protocol. Verify documentation consistency, links and evidence. Customer validation remains pending. Application implementation is outside this milestone.
