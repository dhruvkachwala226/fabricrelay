# Challenge: Build with Codex One-Month Challenge

We are starting a completely new solo project.

## Project Overview

FabricRelay is a multi-tenant B2B textile catalog
and wholesale inquiry management platform.

Textile wholesalers can digitize fabric swatches,
manage textile specifications, colorways, prices
and availability, and publish branded catalogs.

Public buyers can browse fabrics and request
physical samples or wholesale quotations.

## User Roles

1. SUPER_ADMIN
2. WHOLESALER_ADMIN

Public buyers do not require authentication.
